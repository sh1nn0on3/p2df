# P2DF Email Digital Forensic System

Hệ thống **Email Digital Forensic** theo mô hình **P2DF (Privacy-Preserving Digital Forensics)** - Lab mô phỏng cho luận văn.

## 🎯 Mô tả

Hệ thống cho phép:
- **Admin**: Upload và mã hóa email dataset, phê duyệt yêu cầu giải mã
- **Investigator**: Xem metadata email, gửi yêu cầu giải mã, tự giải mã khi được duyệt
- **Logging**: Ghi nhật ký toàn bộ hoạt động điều tra

## 🔐 Công nghệ mã hóa

- **AES-256-CBC**: Mã hóa nội dung email (symmetric)
- **RSA-2048**: Mã hóa AES key (asymmetric)
- **SHA-256**: Verify tính toàn vẹn dữ liệu

## 📋 Yêu cầu hệ thống

## 🚀 Cài đặt

### 1. Clone và cài đặt dependencies

```bash
cd D:\education\do-an\email
composer install
```

### 2. Cấu hình database

Tạo file `.env`:

```bash
cp .env.example .env
```

Sửa cấu hình database trong `.env`:

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=email_forensic
DB_USERNAME=root
DB_PASSWORD=your_password
```

### 3. Tạo database

```bash
# Trong MySQL
CREATE DATABASE email_forensic CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 4. Sinh Application Key

```bash
php artisan key:generate
```

### 5. Chạy migrations và seeders

```bash
php artisan migrate --seed
```

**Lệnh này sẽ:**
- Tạo các bảng cần thiết
- Tạo 3 users (1 admin + 2 investigator)
- Sinh RSA key pairs cho mỗi user
- Tạo 5 email mẫu đã mã hóa

### 6. Khởi động server

```bash
php artisan serve
```

Truy cập: `http://localhost:8000`

## 🔄 Quy trình P2DF

### 1. Admin Upload Email
```
1. Upload CSV file
2. Generate unique AES-256 key per email
3. Encrypt email body with AES key
4. Encrypt AES key with Admin's RSA public key
5. Store in database
```

### 2. Investigator Request Decryption
```
1. Browse encrypted emails (metadata only)
2. Submit decryption request with reason
3. Wait for admin approval
```

### 3. Admin Approve Request
```
1. Decrypt AES key using Admin's RSA private key
2. Re-encrypt AES key using Investigator's RSA public key
3. Update request status to 'approved'
```

### 4. Investigator Decrypt Email
```
1. Receive encrypted AES key
2. Decrypt AES key using Investigator's RSA private key
3. Decrypt email body using AES key
4. View plaintext content
5. Verify hash for integrity
```

## 🗃️ Database Schema

### users
- id, name, email, password
- **role**: admin / investigator
- **public_key_path**, **private_key_path**

### emails
- id, from, to, subject
- **body_encrypted**: AES-encrypted content
- **aes_key_encrypted_admin**: RSA-encrypted AES key
- **hash**: SHA-256 for integrity

### decryption_requests
- id, email_id, investigator_id
- **status**: pending / approved / rejected
- **reason**: Why need to decrypt
- **aes_key_encrypted_inv**: Re-encrypted AES key for investigator
- approved_at

### forensic_logs
- id, user_id, role, action, target_id
- ip_address, details (JSON)
- created_at

## 🔍 Các tính năng

- ✅ Duyệt/từ chối yêu cầu giải mã

- ✅ Tự giải mã email khi được phê duyệt

- ✅ End-to-end encryption
- ✅ Role-based access control
- ✅ Audit trail (forensic logs)
- ✅ Hash verification for integrity
- ✅ Private keys never leave server

## 🛠️ Troubleshooting

### Lỗi: "Admin public key not found"
```bash
# Chạy lại seeder để tạo RSA keys
php artisan migrate:fresh --seed
```

### Lỗi: "Class 'CryptoService' not found"
```bash
composer dump-autoload
```

### Lỗi khi upload file
```bash
# Kiểm tra quyền storage
chmod -R 775 storage
```
